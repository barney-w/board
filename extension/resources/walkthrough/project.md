# Open a Project

Your VM has a sample project ready to explore:

```
~/projects/hello-board
```

This is a simple FastAPI application with Docker Compose. Try:

1. Open a terminal: `Ctrl+`` ` (backtick)
2. `cd ~/projects/hello-board`
3. `docker compose up`
4. Visit http://localhost:8000

To start your real work, clone your team's repository into `~/projects/`.
